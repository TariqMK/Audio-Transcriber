Stays on your computer

Transcription runs on your own machine. Audio and transcripts never leave it. No accounts, no telemetry, no tracking.

Nothing else to install

Audio decoding is built in, so there is no ffmpeg and no Python to set up. Download the app and open it.

Carry it anywhere

Settings, models and logs live in a Verbatica-data folder next to the app. Move them together and everything comes along.

Every word, in the format you need

Pick a model, choose your formats and select Transcribe. Verbatica works through the queue and saves each result next to the others in the folder you chose.

Text and subtitles from one run

Save each result as plain text, SRT or WebVTT subtitles, or any combination. Results are named after their source file and never overwrite an earlier one.

Verified model downloads

          
Each model downloads once and every file is checked against a SHA256 checksum. An interrupted download fetches only the missing files.

Audio and video
MP3, M4A, WAV, FLAC, OGG, MP4, MOV, AVI and MKV.

      
A whole queue
Drag files onto the window. They are transcribed one after another. Remove finished ones in one step.

      
Live waveform
Written parts turn bright and a blue cursor marks the progress.

      
Six model sizes
From tiny at 75 MB to large-v3 at 2.9 GB. Larger is more accurate.

      
Text, SRT, VTT
Choose one format or all three for every file in the queue.

      
Never overwrites
If talk.txt exists, the new result is saved as talk (2).txt.

      
Stops when you say
Stop takes effect within about 30 seconds of audio, mid-file.

      
Progress per file
A percentage on the active row, and word counts on finished ones.

      
Show in Finder
Open the folder of any finished transcript. Show in Explorer on Windows.

      
Resumes downloads
An interrupted model download continues with the missing files.

      
Asks before replacing
A damaged model file is replaced only after you agree and the new copy is verified.

      
Light and dark
Follows the system appearance on every platform.

      
Works offline
With a model downloaded, no internet connection is needed.

      
Updates on request
Check for Updates asks GitHub only when you select it.

      
Lighter engine
Runs on faster-whisper. About half the memory of the original Whisper package.
